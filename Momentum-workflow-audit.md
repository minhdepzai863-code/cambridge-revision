# Momentum Studies workflow audit

Observed in the signed-in student workspace on 13 November 2026. Public references are [Topical](https://www.momentumstudies.com/topical) and [Exam builder](https://www.momentumstudies.com/exam-builder).

| Workflow | Controls and behavior observed | Cambridge Revision implementation checklist |
|---|---|---|
| Past papers | Paper hub opens a searchable catalogue. Qualification, subject, stage, sort, attempted-only, season, year, component and variant narrow results. Rows expose question papers and mark schemes alongside attempt data. | Keep catalogue and personal attempts accessible from the same hub. Pair sources by syllabus, component and session. |
| Topical | Syllabus and chapter controls narrow a question list. Search, sort, shuffle, Saved, Done, Not done, marks and difficulty sit above the list. A question has a separate answer view and original paper link. | Build a two-panel browser from the local syllabus. Show honest coverage, question metadata, source previews and saved/completed indicators. |
| Exam builder | Automatic draw and manual selection are distinct modes. Automatic setup has chapters, question count, time presets and further filters. Manual mode places the question preview next to a paper draft, with reorder and preview controls. Saved papers have their own view. | Use the same question pool and preview for both modes. Keep draft selections, expose shortages and preserve paper order. |
| MCQ | Practice gives immediate feedback. Timed tests use a configurable duration and mark on submission. Real paper starts with year and paper selection. The overview includes mistakes and chapter performance. | Keep timed and immediate feedback separate. Preserve choices across reload and show the original item before asking for an answer. |

Inspection covered the catalogue, Topical, both builder setups, and all three MCQ setup screens. I did not submit a Momentum test or create a saved exam in the reference account. The reference's branding, question assets and database were not copied. Cambridge previews use original source papers available in the project or on this device.
